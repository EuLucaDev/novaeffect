Nova Effect portable mode

While this file sits next to novaeffect.exe, Nova Effect keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the Nova EffectData folder beside it instead of
%APPDATA%\Nova Effect. Copy the whole folder to move Nova Effect with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Nova Effect unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Nova Effect) instead.
If Nova EffectData can't be written (for example on a read-only drive), Nova Effect logs a
warning and uses %APPDATA%\Nova Effect instead.
